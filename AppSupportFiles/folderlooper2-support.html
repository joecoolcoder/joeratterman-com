Folder Looper Support

Play folders from the Files app, then switch into Practice mode to slow down, transpose, repeat, and study one song at a time.

About Folder Looper

Player

Choose a folder from the Files app and Folder Looper continuously plays the supported audio files inside. Browse the play order, jump to a track, reshuffle, and keep listening with background playback.

Practice

Choose one song, or bring the current Player song into Practice. Adjust speed, transpose between keys, repeat the song, and view detected key and tempo details as a helpful rehearsal starting point.

Features

  • Play audio files directly from folders selected in the Files app
  • Supports MP3, WAV, AAC, AIF, AIFF, CAF, and M4A formats
  • Continuous folder playback with optional shuffle
  • Browse play order, jump to any song, and reshuffle anytime
  • Practice mode for working on one song at a time
  • Speed control from 50% to 150% in Practice mode
  • Transpose practice songs from one key to another
  • Repeat a practice song continuously
  • Detect key and tempo for supported audio files
  • Display embedded song artwork when available
  • Background audio, Now Playing, and remote playback controls
  • Remembers your selected folder and playback preferences

Frequently Asked Questions

What audio formats are supported?

Folder Looper supports MP3, WAV, AAC, AIF, AIFF, CAF, and M4A audio files.

Where can my audio files be stored?

Audio files can be stored locally on your device, in iCloud Drive, or in other locations accessible through the Files app.

Does playback continue when the screen is locked?

Yes. Folder Looper supports background audio playback, Now Playing information, and remote playback controls.

Can I shuffle playback?

Yes. Shuffle mode can be enabled or disabled at any time. You can also open Play Order to view upcoming songs, jump to a track, or reshuffle.

What is Practice mode?

Practice mode focuses on a single song. You can slow it down, speed it up, transpose it, repeat it, and use detected key and tempo details while practicing.

How accurate are key and tempo detection?

Key and tempo are estimates based on the audio signal. Results can vary with recording quality, arrangements, intros, outros, live recordings, modulations, and layered instruments.

Why do some songs show artwork and others do not?

Folder Looper displays artwork when it is embedded in the song file metadata. If a file does not include artwork, the app shows default artwork instead.

Do I need to import a folder into a library?

No. Folder Looper works directly with folders you choose in the Files app. Practice songs are copied into app storage so they can be processed for speed and key changes.

Key and Tempo Detection

Detection results are designed to be useful starting points for practice, not final musical authority. Use them as guidance, then adjust by ear when needed.
