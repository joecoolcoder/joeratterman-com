Rehearse Pro Support

Build setlists, loop playback, and prepare songs for rehearsal.

Features

  • Play audio files directly from folders selected in the Files app
  • Build setlists from a folder of songs
  • Optional shuffle playback for setlists
  • Sort setlists using numbered file names when shuffle is off
  • Background audio support
  • Apple CarPlay and lock screen playback controls
  • View song artwork and metadata when available
  • Detect song key and tempo for practice
  • Transpose key and adjust playback speed
  • Loop a practice song with repeat mode

Frequently Asked Questions

What does Rehearse Pro do?

Rehearse Pro combines setlist playback with song practice tools for musicians, singers, and worship teams.

What audio formats are supported?

Rehearse Pro works with common audio file formats supported by iOS, including MP3, WAV, AAC, AIF, AIFF, CAF, and M4A files.

Can playback continue when the screen is locked?

Yes. Rehearse Pro supports background audio playback, lock screen controls, and Apple CarPlay playback controls.

How does setlist sorting work?

When shuffle is off, songs with numbered file names can sort to the top in number order. Songs without numbers appear after numbered songs.

Does the App send my songs anywhere?

No. Your audio files remain on your device. Playback, artwork display, key detection, and tempo detection happen locally.
